## `06 // THE LAB`

I treat algorithms like a gym.

Not because every problem needs the fanciest solution — but because repeatedly solving problems teaches me how to **think**.

```cpp
int main() {

    while (true) {

        learn();
        code();
        debug();
        optimize();

        if (problemSolved())
            celebrate();
        else
            repeat();
    }

    return 0;
}
```

|---|---|
| 🔎 Searching | Binary Search |
| 🔀 Sorting | Merge Sort · Quick Sort |
